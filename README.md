## 💻 How to Run the Programs

Make sure Java is installed on your system.

Check the Java version:

```bash
java -version
```

Check the Java compiler:

```bash
javac -version
```

Compile a program:

```bash
javac ProgramName.java
```

Run the compiled program:

```bash
java ProgramName
```

For example:

```bash
javac HelloWorld.java
java HelloWorld
```
